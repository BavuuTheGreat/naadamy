# Бөхийн Барилдаан

Монгол бөхийн 2D тулаант тоглоом. Хөтөч дээр ажиллана, build хэрэггүй. Сервертэй холбоогүй, бие даасан.

## Ажиллуулах

`index.html`-ийг хөтчөөр нээнэ. Онлайн горимд найз чинь мөн адил файлуудтай байх ёстой (Netlify Drop, GitHub Pages гэх мэтээр байршуулж болно).

## Горим

- **Компьютертэй**: CPU-тэй барилдана.
- **2 тоглогч**: нэг гар дээр. 1-р: `WASD` + `F G H`, шидэх `R`. 2-р: сумнууд + `, . /`, шидэх `M` (эсвэл Numpad `1 2 3 0`).
- **Онлайн**: PeerJS (WebRTC P2P). Нэг нь өрөө үүсгэж 5 тэмдэгттэй код авна, нөгөө нь кодоор нэгдэнэ.

## Удирдлага (ганцаараа / онлайн)

`WASD` эсвэл сумнууд, `J` хөнгөн, `K` хүчтэй, `L` өшиглөлт, `I` барьж шидэх. Хамгаалах: ар тийш барих.

| Мэх | Оролт |
|---|---|
| Бүргэдийн дайралт | ↓ ↘ → + K |
| Арслангийн давшилт | ← → + J |
| Өргөлт (агаарт хөөргөнө) | суугаад K |
| Тах (унагана) | суугаад L |
| СУПЕР (ХҮЧ дүүрсэн үед) | ↓ (тавиад) ↓ + K |
| Шидэлтээс мултрах | шидүүлэх агшинд I |

Комбо: цохилт оногдож байх үед дараагийн товчийг дарна. Жишээ: `J J K` = Төмөр нударга, `J J K ↓↘→K` = Тэнгэрийн бүргэд.

## Бүтэц

- `game.js`-ийн дээд хэсэг нь детерминист симуляц: `Math.random` ашиглахгүй, 60 Hz тогтмол алхамтай. Онлайн горим нь delay-based lockstep: зөвхөн оролтыг дамжуулж, хоёр тал ижил симуляц ажиллуулна. Ping-ээс хамаарч input delay автоматаар тохирно.
- Node дээр `require('./game.js')` гэж симуляцыг тестлэж болно (`newMatch`, `step`, `hashState`).
